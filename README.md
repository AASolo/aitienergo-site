# Айтиэнерго — сайт

Новый сайт ООО «Айтиэнерго» (aitienergo.ru). Статический HTML/CSS/JS, без сборки.

- Страницы: `index.html`, `advantages.html`, `services.html`, `mobile-*.html`, `contacts.html`, `511.html`, `privacy.html`
- Стили и скрипты: `assets/style.css`, `assets/main.js`; шрифты в `assets/fonts`, картинки в `assets/img` (внешних запросов нет)
- Публикация: GitHub Pages через `.github/workflows/pages.yml` при каждом пуше в `main`
- Перенос на другой хостинг: скопировать содержимое репозитория в корень сайта (`.github` и `README.md` можно не копировать)
